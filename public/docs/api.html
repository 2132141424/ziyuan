接口一览

方法与路径说明
GET /api/navigation返回全部分类、子分类与资源条目。
GET /api/site返回站点名称、描述等配置。
GET /api/dl/sign?item=<id>按资源 id 签发带 15 分钟时效签名的下载地址。
GET /api/dl?item=&t=&exp=校验签名后 302 跳转到真实下载地址（需签名，不可直接拼装）。
GET /api/health服务健康状态。

Markdown 表示

首页支持内容协商：请求头带 Accept: text/markdown 时返回 Markdown 版本，并附 x-markdown-tokens；浏览器与默认请求不受影响，仍返回 HTML。

curl -H 'Accept: text/markdown' https://ziyuan.waterfish.ren/
